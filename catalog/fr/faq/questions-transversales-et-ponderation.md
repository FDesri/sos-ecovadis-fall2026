# Comment les questions à cheval sur plusieurs thèmes affectent-elles le score — pèsent-elles plus lourd ?

Certaines preuves contribuent à **plusieurs thèmes simultanément** : un code de conduite fournisseurs, par exemple, peut compter à la fois pour l'Éthique (dispositions anticorruption) et pour les Achats Responsables (exigences de durabilité fournisseurs). Ce bénéfice transversal explique pourquoi les documents complets pèsent plus que les documents étroits, mono-sujet.

La mécanique de pondération dépend du type d'indicateur : les indicateurs Reporting suivent la même formule sur tous les piliers, tandis que les adhésions et certifications peuvent peser différemment selon le pilier. Les questions à cheval sur plusieurs thèmes ne reçoivent **pas de surpondération automatique dans un thème donné** — l'effet multiplicateur vient d'une preuve transversale forte qui améliore plusieurs scores thématiques à la fois, pas d'un indicateur noté plus lourdement.
