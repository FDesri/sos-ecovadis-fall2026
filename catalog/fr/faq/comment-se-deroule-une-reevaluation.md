# Comment procéder pour une réévaluation ?

Quand votre fiche d'évaluation approche de l'expiration, EcoVadis vous notifie pour initier un nouveau cycle. Le processus suit la même séquence : compléter le questionnaire, charger les preuves à jour, soumettre. Important : **une réévaluation peut être plus facile qu'une première évaluation** — certaines réponses sont pré-remplies à partir du cycle précédent, et tous les documents déjà soumis restent accessibles dans la bibliothèque **sans compter dans le nouveau quota de 55 documents**.

Le focus pratique : revoir les réponses pré-remplies, actualiser les politiques et KPI expirés ou obsolètes, ajouter des preuves fraîches, et traiter les points ouverts du plan d'action correctif. Une gap analysis structurée avant soumission est fortement recommandée plutôt que de se fier au pré-rempli.
